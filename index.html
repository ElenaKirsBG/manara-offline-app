Исследуйте ситуацию

Выберите ситуацию и схему. Можно вытянуть карты в приложении или внести вручную расклад из физической колоды Манара.

Оффлайн-разбор собирает общий сюжет из значений всех карт и их связей.

Имя можно заменить псевдонимом или инициалами. Данные хранятся только в истории на этом устройстве.

Укажите 0, если дополнительных карт не было. В ручном режиме ниже появятся поля для ввода каждой карты.

Для каждой позиции нажмите кнопку, чтобы начать перемешивание. Нажмите её снова, когда увидите карту для выбора. После фиксации нажмите кнопку, чтобы перейти к следующей карте.

Нажмите на карту во время анимации, чтобы зафиксировать её.
