# Офлайн-прототип приложения Таро Манара

Мобильный PWA-прототип: каталог 78 карт, двадцать два алгоритма расклада для разных жизненных ситуаций и локальная история.

## Запуск

`index.html` можно открыть локально для просмотра интерфейса: карточные данные подключаются из `cards-bundle.js`. Для установки PWA и работы service worker откройте приложение через HTTPS или localhost. После первого открытия оболочка кэшируется, история хранится в браузере устройства.

## База карт

`cards-major-*.json` и `cards-*.json` — базовые карточные данные. `cards-lessons.js` содержит расширенный учебный слой для всех 78 карт и подключается в офлайн-режиме вместе с `cards-bundle.js`.

В базе есть учебные значения всех 78 карт: ядро и наблюдение за образом, динамика отношений, чувства, мысли, возможные намерения, наблюдаемое поведение, ресурсная и теневая стороны, контексты, совет и риск трактовки. Полные значения доступны в каталоге и раскрываются для каждой карты в раскладе. Связки учитывают теги, масти, старшие и младшие арканы, а также позиции карт. Трактовки предназначены для размышления и не устанавливают факты о другом человеке.

## Расклады

Доступны двадцать две схемы: от карты дня и расклада на отношения до подробного анализа ситуации, решения, успеха дела и повторяющегося сценария, психологического состояния и сопоставления потребностей партнёров. В каждой позиции используются карты колоды Манара. Можно вытягивать карты случайно или вводить ручной расклад физической колоды, добавлять произвольное число дополнительных карт и читать сочетания соседних позиций. В раскладе на четыре сферы центр занимает Старший аркан, а вокруг располагаются четыре карты по стихиям.

## Qwen на устройстве

В списке «Режим трактовки» есть четвёртый вариант: **Qwen на этом устройстве**. Он запускается в браузере через WebGPU; компьютер и локальный сервер не нужны. При первом запуске потребуется интернет и примерно 1,1 ГБ для Qwen 1.5B. После загрузки можно отключить сеть и проверить разбор. На iPhone нужен Safari с поддержкой WebGPU и `shader-f16` (ориентир — iOS 26 или новее), обычная вкладка, свободная память и место в браузерном хранилище. Во время загрузки и генерации держите приложение открытым. Safari может очистить данные сайта, и тогда модель потребуется скачать заново.

Для пересборки Worker выполните `pnpm install`, затем `pnpm run build:qwen`; полученный `qwen-worker.bundle.js` должен быть опубликован вместе с приложением. Скрипт `node scripts/create-pwa-icons.mjs` создаёт золотые значки PWA. Проверьте Qwen на реальном устройстве: наличие WebGPU ещё не гарантирует, что памяти и мощности хватит для стабильной генерации.
